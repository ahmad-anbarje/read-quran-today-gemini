# Read Quran Today for Gemini CLI

The Holy Quran as printed in the Madinah Mushaf (Hafs), in [Gemini CLI](https://github.com/google-gemini/gemini-cli): the Arabic, 127 translations in 88 languages, the Tafsir al-Muyassar, word-by-word meanings, search and recitations, from [readqurantoday.com](https://readqurantoday.com).

```bash
gemini extensions install https://github.com/ahmad-anbarje/read-quran-today-gemini
```

Then ask, for example: *Show me Ayat al-Kursi with the Saheeh International translation*.

Free, with no account or key. It connects to the public MCP server at `https://readqurantoday.com/mcp`; see the site's [privacy policy](https://readqurantoday.com/privacy/).
