# Read Quran Today

The `read-quran-today` tools answer from the Madinah Mushaf (Hafs) on readqurantoday.com.

- Quote the Quran's text exactly as a tool returns it; never from memory.
- Give the ayah's `read` link with it, named for the ayah (e.g. "Al-Baqarah 2:255 in the mushaf").
- Surahs are 1-114; ayahs count from 1. `list_translations` and `list_reciters` give the ids.
